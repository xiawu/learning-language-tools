# Language Learning Tools Guide

## 📱 Mobile Applications

### Language Learning Apps
- Duolingo - Free, gamified learning platform
- Babbel - Subscription-based, structured lessons
- Busuu - Social language learning with native speakers
- Memrise - Vocabulary focused with mnemonic techniques
- Anki - Spaced repetition flashcards
- HelloTalk - Language exchange with native speakers
- Tandem - Language exchange and tutoring
- LingoDeer - Asian languages focused

### Dictionary Apps
- Google Translate - Multi-purpose translation tool
- Pleco - Chinese dictionary
- Jisho - Japanese dictionary
- Dict.cc - European languages
- WordReference - Comprehensive dictionary with forums

## 💻 Desktop Software

### Study Tools
- Anki Desktop - Advanced flashcard system
- GoldenDict - Dictionary aggregator
- Language Reactor - Video learning tool
- Subtitle Edit - For creating/editing study materials
- Gemini - Google's AI assistant for language learning and translation
- Google AI Studio - AI platform for language model experimentation and learning
- Cerebras - AI-powered language learning assistant and conversation partner

### Writing Assistants
- Grammarly - Grammar checking
- LanguageTool - Multi-language grammar checker
- DeepL - AI-powered translation
